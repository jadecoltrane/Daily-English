# English Daily Lesson｜每日英语课

**把英语练习变成每天一页：学几个地道表达、复习旧知识、进入连续的职场故事，然后开口说英语。**

这是一个可以自己搭建的 **Claude Artifact 英语学习系统模板**。它不提供现成的公开学习账号，也不是打开 GitHub 就能直接使用的网站。你需要先在自己的 Claude 环境中创建学习页面并初始化数据。

> **目前状态：可供搭建和改造的项目模板。** 页面构建与数据格式检查已有测试，但“新账号从零发布 → 导入数据库 → 首次出课 → 第二天复习”的完整流程尚未验证。部分账号可能无法使用所需的 Artifact 数据库或 AI 判分功能。

## 它能帮你练什么？

| 功能 | 你会做什么 |
| --- | --- |
| 每日表达 | 学习少量适合真实场景的英文说法，而不只是背单词 |
| 间隔复习 | 回忆以前学过的表达；根据答题结果安排后续复习 |
| 情景故事 | 跟随一个连续发展的职场故事，在对话中练表达 |
| 接着聊 | 用英语回答角色的问题，练习组织自己的想法 |
| 小练习 | 快问快答、根据事实造句、看图描述和“换个说法” |
| 听力 | 根据真实视频的介绍安排听力或隔天复述 |
| 开口练 | 把当天的情景带进语音对话，练习真实沟通 |
| 表达库与答疑本 | 查看学过的表达、已掌握内容和容易混淆的说法 |

课程默认偏向**正在准备国际车企设计岗位求职的人**，覆盖作品集、设计评审、面试、会议以及日常生活场景。你也可以调整学习目标、职业和故事背景。

## 每天怎么使用？

搭建完成后，日常使用不需要运行命令。整个流程是：

**在 Claude 对话里提出“出今天的课” → Claude 根据学习记录生成并保存课程 → 打开自己的 Artifact 学习页 → 完成练习并保存答案 → 下次出课时根据答案安排复习。**

你每天可以发送：

> 请按 Artifact 数据库中的 system/prompt 生成今天的课。页面：**（替换成你自己的 Artifact 链接）**。先读取学习记录并按规则结算复习，再保存今天的课程。不能读取或写入的部分请明确告诉我。

**注意：这是手动触发出课。** 规则中虽然写了上海时间早上 8 点，但本项目没有提供已经验证的自动定时出课功能。

## 第一次使用：搭建自己的学习页

以下步骤只需要做一次。如果你不熟悉代码，可以把项目文件和本节步骤交给 Claude 协助操作，但最终仍需要由你确认页面发布和数据库权限。

### 1. 获取项目文件

在 GitHub 页面点击 **Code → Download ZIP**，下载并解压仓库；也可以使用 Git 克隆。

你需要有：

- 一个可以使用 Claude Artifacts 的账号；还需要确认该环境支持数据库读写和 AI 判分。
- 能运行 Python 3 的环境，用于生成自己的页面；没有本地环境时，可让具备代码执行能力的工具协助。
- 自己的姓名/称呼、英语水平、学习目标，以及希望在故事里练习的真实或虚构场景。

### 2. 填写个人学习配置

复制 `config.example.json`，将副本命名为 `config.json`，修改其中四项：

| 配置项 | 填什么 |
| --- | --- |
| `LEARNER` | 你希望页面如何称呼你 |
| `ROLE` | 你的职业或身份 |
| `GOAL` | 你希望英语帮你完成什么目标 |
| `LEVEL` | 你当前的英语水平 |

示例配置仅供演示，不代表系统已经知道你的个人信息。

在仓库文件夹运行：

```bash
python3 tools/build.py config.json
```

成功后会生成 `dist/index.html`。它就是根据你的配置生成的学习页面。`config.json` 和 `dist/` 已加入 Git 忽略列表；**不要将填写了真实私密信息的配置或页面公开提交**。

### 3. 在 Claude 中创建 Artifact

在 Claude 对话里上传生成的 `dist/index.html`，请求将其作为 Artifact 学习页发布。

**这一步必须确认两个功能是否可用：**

- **数据库（`db`）**：保存课程、表达库、答题结果和故事进度。
- **AI 调用（`sample`）**：为页面中的部分判分和情景交互提供模型能力。

页面当前使用 Claude Artifact 专有的 `claude.use("db")` 和 `claude.use("sample")`。如果你的账号或运行环境不支持，页面可能无法正常读写或使用部分 AI 功能；**仅上传 HTML 并不等于搭建成功**。

发布后保存自己的 Artifact 页面链接。

### 4. 初始化出课规则和学习数据

使用以下项目文件：

- `prompt/system-prompt.template.md`：每天如何生成课程的规则。
- `seed/story-state.json`：故事人物、求职目标、作品经历与进度的初始数据。
- `seed/bank-phrases.json`、`seed/bank-usage.json`、`seed/bank-rules.json`：表达库、答疑本和思维规律的初始数据。
- `docs/DATA_SCHEMA.md`：数据库中每份内容应该存放在哪里。

先替换规则模板中的学习者信息、个人简介和 Artifact 链接，并填写故事状态中的 `{{FILL...}}` 占位符。不要凭空编造自己的真实工作经历或项目成绩。

然后请有数据库访问权限的 Claude 将其写入：

| 数据位置 | 保存什么 |
| --- | --- |
| `system/prompt` | 完整出课规则 |
| `story/state` | 故事与长期学习状态 |
| `bank/phrases` | 表达库 |
| `bank/usage` | 答疑本 |
| `bank/rules` | 英语思维规律 |

数据库初始化完成后，再按上一节的日常指令试着生成第一课。如果 Claude 无法调用相应数据库工具，应停止并报告，不能只声称“已导入”。

### 5. 检查是否真的搭建成功

至少亲自验证以下连续操作：

1. 出第一课，学习页能显示新表达、故事、练习和复习区域。
2. 在页面完成一次答题，刷新或重新打开后，答案依旧存在。
3. 让 Claude 读取这份真实答题记录，再生成下一课，检查复习安排是否正确。
4. 如果有 AI 判分功能，分别试一次正确回答、接近正确、换用另一种自然表达。
5. 检查故事进度和表达库没有因为重新出课丢失。

这是建议的验收方法，**不是本仓库已经完成的端到端测试结果**。

## 常见问题

**Q：点开这个 GitHub 仓库，就能直接上课吗？**

不能。仓库保存的是学习页模板、规则和示例数据。你需要先按上面的步骤在自己的 Claude 环境中创建 Artifact。

**Q：每天要写代码吗？**

不用。初始搭建需要生成页面，之后的日常出课可以通过 Claude 对话触发；前提是你的 Artifact 和数据库配置已完成。

**Q：学习记录存在 GitHub 吗？**

**目前不是。** 这版仍把真实课程、答案和故事进度保存在 Claude ArtifactData 中。GitHub 主要保存项目代码、模板及文档。仓库没有附带原作者的真实学习记录。

**Q：可以直接用 ChatGPT 生成课程吗？**

课程规则和 JSON 数据格式可以供不同 AI 阅读，但现有页面的数据读写与 AI 交互仍依赖 Claude Artifact 的专有能力。跨平台共用学习记录的完整方案尚未实现。

**Q：可以自动在每天早上 8 点出课吗？**

还没有验证的自动定时功能。目前推荐每天主动发送一次出课指令。

**Q：旧课程会保存吗？**

规则中要求：超过 7 天的旧课先把答题等记录归档到 `history/`，核验成功后再清理旧课程正文。**这项流程尚未在真实数据库中完成验证，也不能替代备份。**

**Q：课程语言、职业场景和时区能调整吗？**

可以修改模板和规则，但并非所有地方都已经参数化。当前默认学习材料偏 B1 难度、以设计求职场景为主，日期按上海时间计算，部分提示词默认使用 `she/her`。更换职业、代词或时区时要检查整个配置和出课规则。

## 隐私、安全与现有限制

- **请勿把真实答题记录、工作经历、个人资料或 API 密钥上传到公开仓库。** 本仓库是公开项目模板，不包含原作者的学习记录和个人版对照文件。
- 真实 ArtifactData 的访问权限因账号和设置而异，本项目尚未验证所有权限场景。
- 复习安排目前主要写在文字规则中，没有独立、完整测试过的复习计算程序；`story/state.teacherNotes` 里的后续纠正优先于旧规则，尤其是**不能在出课时提前增加复习次数**。
- 已知风险包括备份不足、并发写入覆盖、部分错误未明确提示等。技术细节见 [已知问题](docs/KNOWN_ISSUES.md)。
- 本项目还**没有选择开源许可证**。仓库公开可见不等于已经授权任意复制、修改或商用。
