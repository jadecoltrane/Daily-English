# Daily English｜Claude 原生个性化英语学习系统

**每天一页英语课：新表达、间隔复习、连续故事和口语练习。**

Daily English 是一套为 Claude Artifacts 设计的英语学习系统。用户使用**自己的 Claude 账户、自己的 AI 使用额度、自己的 Artifact 数据库**。同一套教学系统可以根据不同人的水平、目标和学习记录生成不同课程。

> **项目状态：产品架构与交付文档公开；正式通用版 HTML 尚未在此仓库发布，也未完成全部售前验收。** 本仓库已清理早期页面模板、独立 Prompt、Python 构建脚本、示例配置和旧版种子数据，避免和目前的 V2 架构混淆。这里是产品文档，不是可直接安装的软件包或网页。

## 核心体验

| 功能 | 使用方式 |
| --- | --- |
| 每日表达 | 根据个人学习目标、水平和场景学习自然表达 |
| Review Cards | 按 `got / fuzzy / miss` 记录安排间隔复习 |
| Drills | 复练错误、替换场景、主动组织英文表达 |
| 连续情景故事 / 接着聊 | 根据学习者的实际反馈发展对话 |
| Listening / Speaking | 听力任务、口语角色扮演与反馈 |
| 表达库 / 答疑本 | 保存学过的表达、已掌握内容、混淆用法 |
| 英语表达与思维训练 | 根据真实输出纠正信息组织、句法、搭配、语气等问题 |

以上是正式通用版的产品目标。**公开文档不能代替真实 Claude 账户中的安装和功能测试。**

## 运行方式

```text
用户收到正式版 HTML
       │
       ▼
在自己的 Claude 创建独立 Artifact
       │
       ├─ HTML：页面 + System Prompt + 教学脚本
       │
       └─ 自己的 Artifact 数据库
            ├─ story/state        个人档案与故事进度
            ├─ bank/*             表达库、答疑本、规则参考
            ├─ days/日期          每日课程、回答和批改
            └─ history/日期       历史归档
```

- **新用户**：库里没有 `story/state` 时才初始化学习目标、水平、时长和偏好场景；表达库从空开始。
- **已有用户**：更新的是原 Artifact 的 HTML 和教学规则，必须保留原来的数据库与复习进度，不得重新初始化。
- **个性化修改**：用户可以让 Claude 调整自己副本的教学规则，不需要作者长期代管。
- **备份**：用户可以让有权限的 Claude 只读导出 Artifact 数据库完整 JSON，保存在 Claude 之外；导出 HTML 本身不包含学习历史。
- **更新**：计划一次性交付、仅修复必要的严重 Bug，不提供服务器、会员订阅或自动推送更新。

作者曾在自己的环境中实测：Claude 免费账户可以通过 HTML 创建独立 Artifact。不同账户的 AI 功能、数据库读写、跨天续学等仍需逐项验证，不能由单次测试推断所有账户通用。
