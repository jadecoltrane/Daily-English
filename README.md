# English Daily Lesson（每日英语课）

一个"每天一页"的英语学习系统：Claude 每天早上出课，写进数据库；学习页读取后给你做复习卡、情景对话、小练习、听力和开口练；你的答题结果写回，第二天据此安排复习。

> 这套东西由三部分组成，缺一不可：**页面**（`app/`）、**规则说明书**（`prompt/`）、**数据库初始数据**（`seed/`）。
> 核心业务规则（复习日期怎么排、故事怎么推进）写在**规则说明书**里，不在页面代码里。详见 `docs/ARCHITECTURE.md`。

## 仓库里有什么

| 路径 | 内容 |
|---|---|
| `app/index.template.html` | 学习页（单文件，约 1280 行），个人信息已换成 `{{占位符}}` |
| `config.example.json` | 要填的 4 个值：姓名、身份、目标、水平 |
| `tools/build.py` | 把模板 + 你的配置 → `dist/index.html`（只替换占位符，不改页面逻辑） |
| `prompt/system-prompt.template.md` | 规则说明书模板（每天出课的全部规则） |
| `seed/` | 数据库初始数据：空的表达库/答疑本、`英语思维规律`、故事状态模板、规则文档 |
| `tools/validate.py` | 只读一致性检查（不写任何东西） |
| `docs/` | 架构说明、数据结构、已知问题、一份示例课文档 |
| `reference/` | 出于隐私保护，此上传版已移除原作者的原版页面和规则说明书。 |

不包含：原作者的学习记录、答题内容、故事进度、表达库内容。

## 新用户怎么搭（对话里让 Claude 帮你做）

1. **填配置**：复制 `config.example.json` 为 `config.json` 并修改，然后运行
   `python tools/build.py config.json`，得到 `dist/index.html`。
2. **发布页面**：在 claude.ai 的对话里上传 `dist/index.html`，让 Claude 发布成 Artifact，并声明能力 `{db: {}, sample: {}}`。
   页面只用了这两项：`claude.use("db")`（读写数据）和 `claude.use("sample")`（AI 判分与情景对话）。
3. **填写并导入数据**：
   - 填好 `prompt/system-prompt.template.md` 里的 `{{LEARNER}}`、`{{LEARNER_PROFILE}}`、`{{ARTIFACT_URL}}`（第 2 步得到的链接）。
   - 填好 `seed/story-state.json` 里所有 `{{FILL…}}`（公司、故事计划、你的真实作品和角色等）。
   - 让 Claude 用数据库写入功能写入：`system/prompt`、`bank/phrases`、`bank/usage`、`bank/rules`、`story/state`。
     文档位置和字段见 `docs/DATA_SCHEMA.md`。
4. **每天出课**：每天对 Claude 说"按 system/prompt 出今天的课。页面：<你的链接>"。它会读前一天结果、结算复习、写入当天的课。
5. **检查**：把数据库导出成 JSON，运行 `python tools/validate.py <导出文件夹>`。

## 需要改成你自己的地方

- 页面里的日期按**上海时间（UTC+8）**计算（原页面第 1199 行 `8*36e5`），页面文案写着"每天早上 8 点"。其他时区需要自行修改。
- 说明书里的"每天 8:00 上海时间"、每周各天的主题（作品集、面试、会议……）是为"求职国际车企的设计师"定制的，换职业需要改写。
- 说明书和页面提示词里仍有 `she / her`，默认学习者是女性。
- 页面的 AI 判分模型写死为 `claude-sonnet-5-5`（原页面第 895 行）。
- 页面里的听力来源是 Nielsen Norman Group 视频页，面向 UX 方向。
