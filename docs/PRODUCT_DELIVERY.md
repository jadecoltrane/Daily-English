# Daily English：交付、初始化、备份和验收规范（计划）

此文档记录**计划中的通用商品版要求**，不是已发布版本的功能保证。当前仓库提供公开参考；完整待售 HTML 不应直接提交到本公开仓库。

## 一、交付定位

- **方案 B：用户拥有独立 Artifact。** 使用者在自己的 Claude 账户中创建自己的 Artifact，使用自己的 Claude AI 能力和数据库，不连接作者的学习数据库。
- 一次性销售完整学习系统，而不是 Claude 会员或作者托管的 AI 服务。买家可以自行修改 Prompt 和个人学习目标；不设计强制会员、授权 API、服务器或持续在线同步。
- 作者主要修复严重 Bug，不承诺定期功能升级；自行修改后的行为及兼容性需说明边界。
- 交付物建议包括：单文件完整 HTML、安装/初始化指南、用户自行修改指南、数据导出指令、常见问题及使用限制。
- HTML 可复制，技术上不能可靠防止二次传播。授权条款可以说明购买者使用和分发权限，但不能假装有不可绕过的 DRM。

## 二、安装和第一次学习

新用户：
1. 获取正式版单文件 HTML，使用自己的 Claude 账户在对话中创建**独立** Artifact，核对它确实不是作者原有学习页面。
2. 确认当前账户/Artifact 的数据库和页面 AI 功能能正常使用。用户实测某些免费账户可操作；其他账户与后续套餐政策仍需按实际条件测试。
3. 检测 `story/state`：若不存在，再询问称呼、学习目标、水平、每天时长、偏好场景，行业和真实经历选填；绝不预设车机设计求职者。
4. 建立最小的空库（`bank/phrases`、`bank/usage` 等）并生成第一课。首次没有旧错误库时正常出题。
5. 表达库按钮始终可见；初始化前/空库时显示准确的状态，不得无限卡在“正在读取”。
6. 出完第一课，刷新仍可看到学习内容；下一次出课读取上次真实答案并结算到期复习。

已有用户：
- 同一 Artifact 的 `story/state`、`bank`、`days`、`history` 存在时，直接继续，不重新填写资料、不导入空 seed、不清空故事进度。
- 修改 HTML 或 Prompt 时只操作用户**原来的 Artifact**；若创建了新的 Artifact，数据不会凭 HTML 自动迁移。
- 页面内 AI Prompt（批改、Drills、故事互动）、`snapData` 与实际执行脚本需要一起检查是否通用，不能只修改一段 System Prompt。

## 三、英语表达与思维训练

旧版固定十条只作为参考示例。正式通用版应基于真实用户输出动态识别句法、搭配、信息组织、语气及交互问题，解释具体差异；自然、正确的英语不能为了教学硬改成参考答案。旧版 `bank/rules` 数据继续兼容；不把用户反复犯的错误写成“所有用户必须遵守的新定律”。

## 四、备份（不在页面内开发导入导出系统）

买家和作者均可以直接让有该 Artifact 数据库权限的 Claude **只读**导出所有实际存在的集合/文档，包括 `story`、`bank`、`days`、`history`，完整保留文档 ID、字段、日期及数组，生成 JSON 下载并保存到 Claude 之外。

可复制的备份请求：

> 请只读列出此 Artifact 数据库中所有实际存在的 Collection 和 Document，并把全部原始数据（含 story、bank、days、history，不能只导出最近 7 天）导出成 JSON 文件。保留 Collection/Document ID 与所有字段；报告各集合数量、导出错误及无法读取的项目。禁止修改原库。

若账号遗失，需在新 Claude 账户中创建独立 Artifact，再明确指定目标库恢复 JSON，**先核对并备份目标库、再写入并逐项校验**。新账号不会自动继承旧 Artifact 的数据库。当前尚未实际验证完整跨账号恢复流程，不能承诺一键恢复。

## 五、重大 Bug 修复

发布修复版时，仅说明确切影响和需修改的 HTML/Prompt 范围。用户可自行修改其副本。若要把官方新版 HTML 应用到既有用户的独立 Artifact，必须先备份，再检查结构兼容，并确认**更新后原数据库仍在**。不承诺自动向所有买家的 Artifact 推送更新。

## 六、正式销售前必须通过的实测

| 用例 | 通过标准 |
| --- | --- |
| 新免费用户首次安装 | 能建立独立 Artifact，能够使用所需 AI/数据库功能；如有账户限制如实列出 |
| 初始空表达库 | 按钮可见，正常显示零记录/初始化引导 |
| 首日课程 | 按真实配置出课，不出现写死的姓名、UX/车机及其他旧设定 |
| 次日课程 | 根据昨天的结果安排复习，不预结算未作答卡 |
| Review Cards / Drills | 批改和练习规则正确，保留原来的完整教学机制 |
| 历史数据 | 页面刷新与再次登录后仍可读取 |
| 隔离 | 两个 Claude 账户/Artifact 看不到彼此的学习记录 |
| 老用户升级 | 原来的表达、故事、复习进度不受 HTML 更新影响 |
| 备份 | Claude 能全量导出而不修改数据库；导出的 JSON 可脱离 Claude 保管 |
| 恢复 | 新 Artifact 完整恢复并继续出下一课；未测通不得声称支持 |

## 七、已知边界

- 仅导出 HTML ≠ 导出学习记录。
- HTML 在浏览器本地双击打开 ≠ 已获得 Claude Artifact 的 AI/数据库能力。
- 新 Artifact ≠ 自动继承原 Artifact 的数据。
- 手动出课 ≠ 每天自动定时出课。
- 「在一个免费账号中测试成功」≠ 对全部免费账号提供可用性保证。
- **公开仓库中的旧模板 ≠ 通用商品版**。
