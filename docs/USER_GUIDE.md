# Daily English｜Claude 用户使用指南（通用商品版计划）

> **当前状态：使用流程草案，供未来正式交付包参考。** 本公开 GitHub 仓库现在仍是旧版技术参考，**不包含已经验收的通用商品版 HTML**。需要拿到正式版 HTML 后，才能执行下文的安装步骤；以下不能被解释为旧模板已经支持全部功能。

## 产品是什么

Daily English 是在**你自己的 Claude 账户**中运行的 Artifact 英语学习系统。HTML 负责页面、出题和教学规则；你的 Artifact 数据库保存个人目标、历史课程、回答、表达库及复习进度。作者不会替你提供 Claude 账号、AI 额度或托管数据库。

你获得的是一次性交付的 HTML 学习系统，可以自行让 Claude 修改自己副本内的 Prompt 和功能；不含无限模型调用、定时自动出课或持续功能升级承诺。

## 安装（收到正式交付 HTML 以后）

1. 使用你自己的 Claude 账户，打开一个新对话。
2. 上传**正式版完整 HTML**（不是本仓库的 `app/index.template.html` 早期模板）。
3. 向 Claude 发送：

   > 请基于我上传的 HTML 创建**属于我账户的独立 Claude Artifact**，保留完整页面、`snapData`、内嵌 System Prompt 和 JavaScript。不要连接或修改作者的 Artifact。请确认创建结果，并在当前环境可用的范围内检查数据库和 AI 交互功能；任何无法验证的能力请明确指出。

4. 打开生成的**自己的** Artifact，检查页面、表达库按钮是否显示，以及数据是否能够读取/保存。**仅出现页面不等于已经完成安装。**
5. 在能访问该 Artifact 的 Claude 对话中发送：

   > 请读取**我的这个 Artifact 页面中** `snapData.cols.system.prompt.text` 的出课规则，并检查该 Artifact 自己的数据库。若 `story/state` 不存在，按 First run 规则引导我初始化称呼、英语水平、目标、每天时长和偏好场景（职业、项目经历选填），创建空表达库，然后生成第一课。若 `story/state` 已存在，则不要重新初始化，不要清空记录。不要使用作者原有 Artifact 的 URL 或数据库。

6. 按自己的实际情况回答初始化问题；确认第一课生成并显示。刷新或重新打开页面，核对内容仍在，才算完成基本安装。

**特别注意：** Claude 是否能直接从页面完成初始化、是否需要在对话中操作 Artifact 数据库，都取决于正式版本和当前账号的实际能力。不能凭这份文档保证所有账号、所有套餐完全一致。

## 每天怎么学习

向有权限访问**自己 Artifact** 的 Claude 发送：

> 请按我当前 Artifact HTML 的 `snapData.cols.system.prompt.text` 出今天的课。先读取我的 `story/state`、表达库、最近课程和实际作答结果，按规则安排复习，再写入我自己的 Artifact 数据库。不得提前把未作答卡片记为已复习；如果写入失败，请明确告知。

打开自己的学习页面完成复习、Drills、对话、听力和口语练习。学习记录保存在自己的 Artifact 数据库；**HTML 文件本身不含你的历史答案**。

**每日手动出课 ≠ 自动定时出课。** 页面和 Prompt 不会因为写了一个时间，就自动得到定时执行权限。

## 表达库：为什么一开始是空的？

「表达库」按钮来自 HTML，真实内容存在自己的 `bank/phrases`（`rows`、`mastered`）和 `bank/usage` 中。

- 新用户数据库尚未初始化：应该显示初始化提示，而不是无限「加载中」。
- 已初始化但还没学过表达：分类为空、数量为零，属于正常状态。
- 第一课以后：新表达和实际复习进度逐渐进入自己的数据库。
- 如果一直显示「正在读取」，应先确认 Artifact 数据库是否能访问，不要反复清空重建。

上述空状态是**正式通用版的验收要求**，不能视为本仓库早期模板已经实现。

## 如何自己修改规则？

你可以让 Claude 在自己的 Artifact 中调整主题、难度、出题偏好及英语表达训练方式。重要的是说明：

> 只修改**当前 Artifact 的页面代码或 HTML 中的 Prompt**，不要重建一个空数据库，不要清空 `story/state`、`bank`、`days`、`history`。如果改动涉及数据字段，先列出兼容性影响并备份。

系统原本的连续故事、Review Cards、Drills、表达库和复习间隔应保持互相兼容。自行定制的规则可能改变学习效果，也可能影响后续补丁的兼容性。

## 如何备份个人学习数据？

**不需要 HTML 内置备份按钮。** 在仍然能使用旧账户时，让有数据库访问权限的 Claude 只读导出：

> 请对我当前的 Artifact 数据库执行**只读完整备份**：先列出实际存在的所有 Collection 和 Document，然后导出所有文档的原始 JSON（至少包括 `story`、`bank`、`days`、`history`，如有其他集合也全部导出），保留每条文档的集合名、ID、完整字段、日期和数组；不能只导出页面显示的最近七天。生成可下载文件，报告每个集合的数量及遗漏、失败。**禁止修改原数据库。**

将 JSON **下载并保存在 Claude 账户之外**。另行保留当前能运行的 HTML；**HTML 与 JSON 备份不是同一个东西**。

账号丢失后，在新账号创建独立 Artifact，再让 Claude导入 JSON 并逐条核对数据。恢复前需要验证新数据库权限及字段兼容性，绝不能仅凭“上传成功”就认定恢复成功。目前**完整跨账号恢复尚需实测**。

## 如果以后有重大 Bug 修复

- 原则上更新**现有 Artifact 的 HTML**，不要新建一个与旧记录无关的空 Artifact。
- 更新前先只读导出个人数据；检查新旧字段兼容性，再替换代码/规则。
- 更新后确认表达库数量、复习日期、最近答案、故事进度未改变，再正常出课。
- 正式版不承诺自动向每个用户副本推送更新；作者只计划处理必要的严重 Bug。

## 常见问题与边界

**Q：我拿到 HTML，直接双击就能用吗？** 不能保证。本系统依赖 Claude Artifact 的专有 AI 与数据能力，独立浏览器打开不等于安装。

**Q：打开作者分享的 Artifact 就等于我有自己的数据库吗？** 不是。正式方案是**用户独立创建 Artifact**，并验证数据确实在自己的环境中保存。

**Q：为什么新用户没有原作者的表达库？** 因为购买者只获得通用 HTML，不获得原作者的个人数据；每个人从自己的空库开始。

**Q：Claude 免费用户可以用吗？** 原作者在部分免费账户上实测过用 HTML 创建独立 Artifact。AI 调用、持久化、跨天续学仍以具体账户和版本的实际运行结果为准。

**Q：我怎么恢复原来的故事？** 需要事先导出的全部数据库 JSON；仅有 HTML 不能恢复学习历史。

**Q：我购买后可以修改 Prompt 吗？** 可以修改自己的副本。是否允许再次分发或转售，需按购买时的授权条款处理。该工具不是 Claude 官方产品。
