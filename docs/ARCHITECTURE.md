# 系统地图（给非程序员）

```
每天早上                         全天                          第二天早上
┌──────────────┐  写入   ┌──────────────────┐  读取   ┌──────────┐  写回答题结果  ┌──────────────┐
│ Claude 对话   │ ──────► │ 数据库            │ ◄────── │ 学习页    │ ─────────────► │ 数据库         │
│ 按说明书出课  │         │ days/今天          │         │ (HTML)    │  results/typed │ days/今天(更新) │
└──────────────┘         │ bank/* story/state │         └──────────┘                └──────┬───────┘
       ▲                 └──────────────────┘                                              │
       └──────────────── 读取昨天结果，结算复习日期 ◄───────────────────────────────────────┘
```

| 部分 | 职责 | 备注 |
|---|---|---|
| 学习页 `app/` | 显示卡片和练习；记录答案；调用 AI 判分/生成情景对话；"表达库"查看页 | 单文件；页面写入用 `update`（合并写入） |
| 规则说明书 `prompt/` | **核心业务规则**：每天出什么、复习日期怎么排、故事怎么推进、各种格式要求 | 是一段文字，由 Claude 每天执行，不是程序 |
| 数据库 | **数据存储** | 见 `DATA_SCHEMA.md` |
| 页面里的判分 | AI 判分提示词（`got / fuzzy / miss`）+ 字符串比对兜底 `gradeTyped` | 判分结果直接决定第二天的复习日期 |

两处"规则"要同时看：说明书决定**出什么课、怎么排复习**；页面决定**答案怎么判**。
