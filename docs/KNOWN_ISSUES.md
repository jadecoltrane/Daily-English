# Daily English｜已知风险与测试状态

> 本文列出**通用商品版 V2 尚待验证的事项**，不是宣称当前线上 Artifact 已发生这些故障。公开仓库已移除早期源代码、旧 Prompt、旧数据库种子和课程样例；历史审计记录依然可在 Git 提交历史中追溯，但不能代表最新线上版本的运行结果。

| 优先级 | 项目 | 验收标准 |
| --- | --- | --- |
| 高 | 新免费账户安装与权限 | 用户能创建自己的 Artifact，实际调用 AI、读写数据库，并在刷新后保留数据；失败时明确列出账户或环境限制 |
| 高 | 数据隔离 | 两个独立用户/Artifact 的 `story/state`、`bank`、`days` 不互相读取 |
| 高 | 老用户无损更新 | 原 Artifact 替换 HTML 后，个人档案、表达库、历史课程、故事和复习进度不丢失 |
| 高 | 完整备份与跨账号恢复 | Claude 能只读导出全部集合、文档和 ID；在新 Artifact 中写回、核对数量和关键字段，并继续出下一课 |
| 高 | 复习结算正确性 | 未完成的卡片不提前增加复习次数；复习到期日期和重新出课的状态一致 |
| 高 | 并发写入保护 | 同一天的页面答题与 Claude 出课不会静默覆盖答案；出错时报告 |
| 中 | 通用化个人 Prompt | 课程生成和页面内 AI Prompt 都不写死姓名、UX、车机、公司和固定学习水平 |
| 中 | 表达库空状态 | 区分“正在读取”“未初始化”“空列表”和“读取失败”，新用户不会无限加载 |
| 中 | 开放式表达与思维训练 | 不再强制套入固定十条编号规则，保留既有 `bank/rules` 的兼容性 |
| 中 | 听力/口语场景适配 | 不强制使用 UX 行业素材，内容根据用户目标变化，引用的外部素材真实可核查 |
| 中 | 原有完整体验 | Review Cards、Drills、连续故事、Listening、Speaking、答疑本等功能在通用化后仍可用 |

## 当前已确认和未确认的边界

- 作者已实际验证在部分 Claude 免费账户中可通过 HTML 创建独立 Artifact；**这不等于**所有账户的数据库、AI 判分和连续学习都已通过。
- V2 的教学规则属于 HTML 内嵌 `snapData`，用户状态属于自己的 Artifact 数据库。旧架构的 `system/prompt` 数据库规则已经弃用。
- 仅下载 HTML 无法取回私人学习数据。数据库备份需由有权限的 Claude 读取并导出完整 JSON。
- 跨账号恢复、原 Artifact 无损更新、跨天复习和数据隔离仍需要真实端到端测试。
- 本仓库是公开文档仓库，**并未发布可供售卖的正式通用 HTML**，不能把说明文档当作已完成的测试报告。

参见 [交付及验收规范](PRODUCT_DELIVERY.md)、[用户使用指南](USER_GUIDE.md) 与 [数据结构](DATA_SCHEMA.md)。
