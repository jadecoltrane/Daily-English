# 已知问题与验收状态

> **此文件分清历史证据和未来商品版的待验证事项。** 原始审计日期为 2026-11-13，当时审查的页面与公开仓库旧模板不完全一致。GitHub 中当前已更新的 README/架构**只是文档更新，不代表 HTML 代码、脚本或线上 Artifact 已同步修复**。本公开仓库未包含完整正式 V2 HTML，无法据此验证当前在线版本。

## 一、面向通用商品版的待验证事项

| 优先级 | 事项 | 为什么需要验证 | 通过条件 |
| --- | --- | --- | --- |
| 高 | 新用户是否能独立安装并访问 AI、数据库 | 作者已在部分 Claude 免费账户上验证可以从 HTML 创建 Artifact，但功能完整性、账号差异尚待复测 | 在独立账户里实际完成首次出课、AI 交互及刷新后数据保留 |
| 高 | 个人版和新用户的数据隔离 | 同一 HTML 不等于同一个数据库，但分享链接、复制与新建的语义不可混淆 | 不同 Artifact 无法读到彼此的 `story/state`、`bank` 和 `days` |
| 高 | 老用户无损升级 | 修改 HTML 可能误触发初始化或使用不兼容字段 | 原 Artifact 更新 HTML 后，表达库、历史、复习进度、故事连续性不变 |
| 高 | 账号遗失后的数据恢复 | HTML 不是数据库备份；用户选择通过 Claude 直接导出 JSON | 真正全量导出并在新 Artifact 写回、核对数量与关键字段，继续出课 |
| 高 | 复习结算与并发写入 | 未作答卡提前 +1、同时页面写回答和出课可能覆盖数据 | 正确结算、保留当天已有答案；失败时不静默覆盖 |
| 中 | 通用化残留个人信息 | 旧代码的 AI Prompt、默认场景、故事设定带有设计求职背景 | 所有页面 Prompt 和生成脚本都从用户资料读取，不写死姓名或职业 |
| 中 | 空表达库状态 | 数据库文档不存在时可能一直显示“读取中” | 加载中、未初始化、已初始化空库、读取失败能区分 |
| 中 | 固定十条表达规律的依赖 | 旧批改和 `bank/rules` 依赖编号 | 开放式批改能解释真实语言问题，同时兼容旧版 `bank/rules` |
| 中 | 听力与视频来源适配 | 原有默认来源偏向 UX 职业方向 | 按用户目标选真实素材，不捏造标题或链接 |

这些是**测试计划，不是已证实的当前线上故障**。已验证的用户反馈只支持：在其实际环境中，免费账户可以从 HTML 创建独立 Artifact；更多功能需另行实测。

## 三、版本与数据边界

- 本仓库 `app/index.template.html`、`prompt/system-prompt.template.md` 是**历史模板**。旧模板使用数据库 `system/prompt`；最新 V2 架构的规则位于 HTML `snapData.cols.system.prompt.text`。
- 原作者的线上 Artifact、个人数据库和正式商品 HTML **不在这个公开仓库中**。仓库说明更新不等于替线上 Artifact 发布新版。
- 公开仓库里保留的旧代码不应被误当作已经修复的商品版。
- 全量数据备份必须包含所有实际集合、文档、ID 和字段；页面最近七天的订阅不等于全量备份。

具体测试路径见 [产品交付规范](PRODUCT_DELIVERY.md) 与 [用户使用指南](USER_GUIDE.md)。
